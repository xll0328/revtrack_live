## Baselines

File:

### TF-IDF + LinearSVC with Leave-One-Out

File:

- predictions: [iclr2024_silver_tfidf_predictions.jsonl](/data/sony/emnlp2026_revtrack/outputs/day0/iclr2024_silver_tfidf_predictions.jsonl)

Result:

- accuracy: `0.54`
- macro F1: `0.175`

Main failure:

- collapses most uncertain cases into `fixed`
- gets much better lexical traction than the heuristic baseline
- still fails almost completely on `partially_fixed`, `unresolved`, and `regressed`

### ModernBERT Embedding + LinearSVC with Leave-One-Out

File:

- predictions: [iclr2024_silver_modernbert_predictions.jsonl](/data/sony/emnlp2026_revtrack/outputs/day0/iclr2024_silver_modernbert_predictions.jsonl)
- metrics: [iclr2024_silver_modernbert_metrics.json](/data/sony/emnlp2026_revtrack/outputs/day0/iclr2024_silver_modernbert_metrics.json)

Result:

- accuracy: `0.44`
- macro F1: `0.263`

Main finding:

- accuracy is lower than TF-IDF because it gives up some easy `fixed` cases
- but it is the first baseline to get non-zero F1 on both `partially_fixed` and `unresolved`
- this makes it more useful for active sampling and boundary analysis

### all-mpnet-base-v2 Embedding + LinearSVC with Leave-One-Out

## Interpretation

The task already shows nontrivial signal even with noisy labels:

1. simple lexical heuristics are not enough
2. a learned text baseline improves substantially but still collapses nuanced states
3. encoder-style semantic models help on nuanced states even when they lose easy majority-class accuracy
4. `all-mpnet-base-v2` is the strongest local baseline so far and should be the default semantic model going forward
5. the real research value is likely in distinguishing `fixed` from `partially_fixed` and `unresolved`, not in finding obvious positive cases
