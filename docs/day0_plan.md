# Day-0 Plan

## Primary Phase

`coding`

## Secondary Phases

- `figure`
- `writing`

## Time Blocks

### Block 1

- finalize the task definition
- collect one public venue slice from OpenReview
- verify the reply taxonomy

### Block 2

- create a manual issue sheet
- adjudicate 20 to 30 examples
- freeze the first label rubric

### Block 3

- run zero-shot baselines on the smoke set
- run one model on the first annotated real subset
- inspect failure clusters

### Block 4

- render the dynamic issue ledger
- decide whether the first signal is sharp enough to continue

## Verification Checkpoints

- every OpenReview field extraction should be inspected on a few raw samples
- every evaluation number must be backed by saved JSONL predictions
- no novelty claim should be made before comparing against adjacent work
- no result should be reported without a concrete example of each error type

## Red Lines

- no fabricated labels
- no synthetic performance claims
- no jumping into training before the benchmark signal is real
